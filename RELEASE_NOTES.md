# SpaceShooter v1.0.0 — Windows

The first standalone Windows x64 release of SpaceShooter. Extract the downloaded ZIP, open the `SpaceShooter` folder, and run `SpaceShooter.exe`. Python and Pygame are not required.

## Included

- Arcade space combat campaign across three alien fleets and an endgame encounter.
- Hangar loadouts, upgrade purchases, settings, tutorial, and gamepad support.
- Bundled game artwork, fonts, music, and sound effects.
- Player progress and settings saved in the Windows user profile. Existing `save_data.json` files beside an older executable are migrated on first launch.

## Controls

- Move: `WASD` or arrow keys; fire: `Space`.
- Reload: `R`; pause: `Escape`.
- While paused: `R` restarts, `M` returns to the title screen, and `Escape` resumes.
- After game over: `R` or `Enter` starts another run; `Escape` returns to the title screen.
- `F11` toggles fullscreen. Controls can be remapped from **KEYBINDS**.

## Notes

- Keep all files in the extracted `SpaceShooter` folder together.
- Windows may show its standard downloaded-app confirmation the first time you launch the game.
